# XRCE-DDS-Study

🎯 我的 XRCE-DDS 学习仓库，使用 Cursor AI 作为学习导师。

## 项目结构

```
XRCE-DDS-Study/
├── .cursorrules              # Cursor AI 导师规则
├── README.md                 # 本文件
│
├── Micro-XRCE-DDS-docs/      # eProsima 官方文档（学习材料）
│   └── docs/                 # .rst 文档
│
├── progress/                 # 学习进度追踪
│   └── tracker.md
│
├── sessions/                 # 学习会话记录
│   └── SESSION-TEMPLATE.md
│
└── notes/                    # 个人笔记
```

## 快速开始

1. 用 Cursor 打开此项目
2. 在 Chat 中开始学习对话
3. 使用特殊指令获取帮助

## 特殊指令

| 指令 | 功能 |
|------|------|
| `@文档 [名称]` | 打开并讲解指定的 .rst 文件 |
| `@目录` | 显示所有可用的 .rst 文档列表 |
| `@进度` | 显示学习进度 |
| `@复习` | 复习已学内容 |
| `@练习` | 基于当前学习内容出题 |
| `@总结` | 总结本次会话 |

## 推荐学习顺序

1. `index.rst` → 理解整体架构
2. `installation.rst` → 搭建开发环境
3. `quick_start.rst` → 运行第一个示例
4. `client.rst` → 深入 Client API
5. `agent.rst` → 理解 Agent 配置
6. `gen.rst` → 学习代码生成工具
7. `transport.rst` → 传输层配置
8. 高级主题...
